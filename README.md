# Backrooms

Juego 3D de terror en el navegador: un elevador que baja y sube por niveles de los Backrooms.

**Jugar:** https://rogergc222004.github.io/Backrooms/

## Multijugador
Jugar → elige una cinta → **Crear sala** y comparte el código de 4 letras, o escribe el código de un amigo y toca **Unirse**.
Las salas se conectan directo entre jugadores (WebRTC con PeerJS); funciona desde redes distintas.
